# Carta del proyecto — plantilla

Entrega de la unidad 1, semana 3. Una pagina. Se sustituye este archivo.

## 1. Mi variante

Numero de variante, y la tabla de reglas copiada de `variantes-tarifarias.md`.

## 2. Alcance

Que entra y —mas importante— **que no entra**. Tres o cuatro vinetas cada una.

## 3. Criterios de aceptacion

Minimo cinco, en sintaxis EARS, verificables:

> Cuando el peso del embarque es exactamente igual al umbral, el sistema
> **debera** cotizar sin recargo por sobrepeso.

Cada criterio tiene que poder convertirse en una prueba. Si no puedes imaginar la
prueba, el criterio esta mal escrito.

## 4. Los tres casos frontera de mi variante

Cual es el limite, cual es el valor justo debajo, cual el justo encima, y que
resultado espero en cada uno.

## 5. Como voy a saber que esta bien

Que corre en CI y que decide que el trabajo esta terminado.
